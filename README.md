# שעות טובות — מחשבון שכר

מחשבון בעברית המבוסס על הסדר ההפרשות בשלושת התלושים שסופקו (יוני–אוגוסט 2026). אתר React/TypeScript/Vite סטטי, ללא חשבון או שרת חישוב. נתוני המשתמש נשמרים רק בדפדפן.

## הרצה ובדיקה

```sh
npm install
npm run dev
npm test
npm run build
```

כתובת מקומית: http://127.0.0.1:5173/. הבנייה נמצאת ב־`dist`; אין פרסום אוטומטי.

## שעות ותשלומים

עשר עמודות לפי התמונה: היעדרות וע״ח שבת בתעריף 100%, ש״נ 100%/125%/150%, שבת 150%/200%, לילה 150%, ש״נ 187.5%/225%. כל שעה מוזנת פעם אחת. תוספות משמרת 20% ו־50% הן תוספות נפרדות לשעות שכבר הוזנו ואינן נספרות כשעות עבודה נוספות.

קצובת נסיעה חודשית 323 ₪ כברירת מחדל, עם אפשרות לבטל או לשנות לפי הזכאות. נסיעות בשבת: מספר נסיעות × 23 ₪. ניתן להזין החזרי הוצאות נוספים והבראה חודשית; לא נגזר סכום הבראה קבוע מתלושים שבהם הסכום משתנה.

הברוטו כולל שכר שעות, תוספות משמרת, החזרי הוצאות והבראה, פחות 1.2% מהשכר הרגיל ו־1.2% מהעבודה הנוספת, בהתאם לתלושים. תוספת כללית חייבת במס ובביטוח אך אינה משויכת אוטומטית לבסיסי הקופות.

## הפרשות אוטומטיות

אין הזנת אחוזים, בסיסים או מתגי פנסיה וקרן השתלמות.

| בסיס | עובד לפנסיה | מעביד לפנסיה | מעביד לפיצויים |
|---|---:|---:|---:|
| שכר רגיל והבראה | 7% | 7.5% | 6% |
| עבודה נוספת לפני הפחתה | 7% | 7.5% | 6% |
| החזרי הוצאות, כולל נסיעות | 5% | 5% | — |

קרן השתלמות: עובד 2.5%, מעביד 7.5%. הבסיס הוא השכר הרגיל וההבראה פחות הפחתת 1.2% מהשכר הרגיל. הפרשות מעביד מוצגות בנפרד ואינן מפחיתות את הנטו. השיעורים שייכים להסדר שבתלושים ואינם הנחה לכל העובדים בישראל. הגדרות הפרשה ישנות בשמירה המקומית אינן משנות את ההסדר הקבוע; שעות וסכומי נסיעות נשמרים.

## מסים ומגבלות

טבלאות 2026 ב־`src/taxData.ts`, מאומתות ב־03.10.2026 מול חוברת רשות המסים המעודכנת לאפריל, עמ׳ 10–12, וטבלת הביטוח הלאומי. נקודת זיכוי 242 ₪. זיכוי פנסיה של 35% מההפקדה הזכאית בכפוף לתקרות. ללא הזנת נקודות זיכוי אין נטו סופי.

אומדן לחודש יחיד, ללא חישוב מצטבר, תיאום מס, זקיפות שווי, הפרשים לחודשים קודמים או זקיפת הפקדות מעביד מעל התקרות. זקיפות ארוחות וביגוד המופיעות בתלושים עשויות להגדיל את המס והביטוח בלי להגדיל תשלום במזומן; כרגע אינן מחושבות. זכאות לחופשה, מחלה והסדרי הפרשה אחרים אינה מחושבת.

ניכויי הפנסיה מעוגלים לכל בסיס בנפרד ואז מסוכמים. הנטו מתאים לסכומי ההורדות המוצגים באגורות. מבחני החישוב כוללים אימות הפרשות מול בסיסי תלוש יולי, לצד מדרגות מס, תקרות ביטוח, קלט, שמירה וביטול נסיעות. מקור התלושים הפרטיים לא מועתק לפרויקט.
