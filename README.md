# מחשבון שכר

אתר סטטי בעברית המבוסס על React, TypeScript ו־Vite. מאפשר לבחור תפקיד ותעריף שעתי, להזין שעות לפי סוג תשלום, תוספות משמרת, כלכלה ונסיעות, ולחשב אומדן ברוטו ונטו לשנת 2026.

## שימוש

בוחרים תפקיד ומזינים נקודות זיכוי מס (כולל 0 אם זו הזכאות), ואז לוחצים על **חשב**. התוצאות מוצגות עם פירוט השכר והניכויים. שינוי נתונים דורש לחיצה חדשה; איפוס מנקה את השדות ומחזיר את הכפתור. נתוני השדות נשמרים בדפדפן בלבד. אין חשבון, שרת חישוב או העלאת נתונים.

כל שדות השעות מציגים 0 כ־placeholder; הוא מוסתר במיקוד. שדות במובייל משתמשים בטקסט בגודל 16px למניעת זום אוטומטי באייפון.

## פיתוח ובדיקה

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

שרת הפיתוח זמין בפורט 5173. תצוגת הבנייה זמינה ב־http://127.0.0.1:4173/. קובצי האתר נבנים לתיקיית `dist`.

## פרסום

GitHub Actions מריץ התקנה, בדיקות ובנייה בכל push ל־`main`, ואז מפרסם את `dist` ל־GitHub Pages. כתובת האתר: https://dimalit778.github.io/calcSalary/.

## הנחות החישוב

- שעות 100%, 125%, 150%, 187.5%, 200% ו־225%; כל שעה מוזנת פעם אחת.
- תוספת משמרת 20% מוזנת בנפרד. בפרופיל הקבוע תוספת 50% נגזרת משעות ע״ח שבת.
- כלכלה גדולה 21.10 ₪, כלכלה קטנה 14.50 ₪, נסיעות סוף שבוע 23 ₪ לנסיעה.
- קצובת נסיעה חודשית ברירת מחדל: 323 ₪ כאשר קיימות שעות עבודה והוזנו תפקיד ונקודות זיכוי.
- הפחתת שכר 1.2% מהשכר הרגיל ומהעבודה הנוספת, בנפרד.
- פנסיית עובד: 7% מהשכר הרגיל והעבודה הנוספת, 5% מהחזרי הוצאות. השתלמות עובד: 2.5% מהשכר הרגיל לאחר הפחתה.
- מדרגות המס, נקודות הזיכוי, זיכוי הפנסיה ותקרות הביטוח לשנת 2026 מוגדרים ב־`src/taxData.ts`, עם קישורים למקורות הרשמים.
- בפרופיל הקבוע תעריפים, שורות שכר, הפחתות, מדרגות ביטוח והפרשות מעוגלים בנפרד לאגורות. הנטו מתיישב עם הניכויים המוצגים.

אלה הנחות של הסדר עבודה מסוים, ולא הסדר אחיד לכל העובדים בישראל. מס הכנסה באתר מחושב לחודש יחיד. אין במסך התאמה לתלוש, חישוב מס מצטבר, פריסת הפרשים, זקיפות שווי או חישוב זכאות לחופשה ומחלה. מנוע החישוב תומך בחלק מהרכיבים האלה לצורך בדיקות פנימיות בלבד.

בדיקות הממשק והחישוב הציבוריות משתמשות בנתוני דוגמה. תלושים, דוחות מקומיים ובדיקות הכוללות נתוני תלושים פרטיים מוחרגים מהמאגר ומקובצי הפרסום.
